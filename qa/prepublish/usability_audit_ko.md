# 사용성 검사

## 수정한 흐름

| 항목 | 기존 문제 | 구현·검증한 동작 |
|---|---|---|
| 연구 시작 | 모델·자료·전송 조건 부족 시 시작 불가 | 무료 실행 준비 검사 → 원인별 수정 버튼 → 직접 유료 시작 |
| 모델 | 설정과 연구 설정에 선택이 분산 | 새 연구에서 상단 5개·제공사별 더보기·직접 등록 |
| CSV | 서버 입력 자료 선택 목록 | 파일 찾아보기·5MB/UTF-8/열 구조 검사 |
| 설정 | 모델·예산 입력 중복 | API 연결·API 검사·예산·성능 최적화·실행 환경 탭 |
| 성능 | 얇은 슬라이더·길게 표시된 추론 안내 | 조작 높이 52px·트랙 14px·손잡이 30px, 아래 현재 단계만 표시 |
| 고급 | 역할과 기능 파악 어려움 | 기본 접힘, 최상위 1·중간 2·하위 1 묶음 |
| 검증 | 차이·비용 불명확 | 분석 도구 → Ridge → F3-P 순서, 짧은 설명·비용 영향 |
| 보고서 | 두 형식의 차이 불명확 | 읽기 쉬운 보고서 / 기술 보고서의 짧은 설명 |
| 도움말 | 많은 문단·카드 | 주제 선택 1개·해당 안내만 표시 |
| 복구 가능한 오류 | 화면 전환 때 작성 내용을 다시 입력 | 같은 앱 세션에서 질문·선택·파일 유지 |
| 인증 링크 | 만료·재사용 오류에서 삭제된 문단 참조 | 재실행 안내 제목, 오류 화면 JS 중단 수정 |

기본값은 medium·자동 검색·읽기 쉬운 보고서다. 검색 자동은 모든 연구의 검색을 뜻하지 않는다. 자료 전송·추가 검증 기능은 자동 허용하지 않는다. 모델·성능·검색·보고서·저사양 설정만 안전한 환경설정으로 기억하며 예산·전송 승인은 기억하지 않는다.

실제 아키텍처의 역할은 4개다. 임의 역할 증감은 구현하지 않고 지원되는 역할별 모델 선택을 묶었다. 정상 모델 선택에서 raw model ID를 입력할 필요가 없으며 직접 등록 경로는 더보기에 보존했다.

## 실제 증거

- `node qa/hardening_visual_qa.cjs`: 실제 Chrome에서 41개 검사. CSV 선택 → 무료 준비 확인 → 기존 FakeProvider 실행 → 보고서 완료를 확인했다.
- `node qa/local_browser_auth_qa.cjs`: 51개 검사. 재사용·만료·재시작·경합·영구 저장소 노출을 확인했다.
- `node qa/connection_ux_visual_qa.cjs`: 66개 검사. 키 등록 실패·rollback·삭제·초록 알림·동의·CSRF를 모의 OS 저장소로 확인했다.
- 모바일·200% CSS 확대·키보드 회귀는 기존 화면 QA에 포함했다. 화면 캡처는 로컬 `output/playwright/`에 보존하고 공개 후보에서 제외했다.
- 성능 슬라이더의 52px 높이는 DOM에서 측정했다. 14px 트랙·30px 손잡이는 적용 CSS와 실제 화면으로 확인했다. 브라우저가 지원하지 않는 range pseudo-element 계산값을 실측으로 기록하지 않았다.

## 요구 검사별 상태

| 검사 | 상태·범위 |
|---|---|
| UX-01 | 설정 파일 수정 없이 API 연결·모델·CSV·시작 가능. 실제 API/OS 키 저장은 미검증 |
| UX-02 | 상단 모델 선택·카탈로그 등록 Chrome 검사 통과 |
| UX-03 | 실제 루프백 인증 Chrome 검사 통과. OS 기본 브라우저·WSF는 미검증 |
| UX-04 | 생성 시 검색 정책 선택·백엔드 적용 검사 통과 |
| UX-05 | 고급 설정·모델 더보기 기본 접힘 검사 통과 |
| UX-06 | 오류·재열기 후 질문/선택 유지 검사 통과 |
| UX-07 | CSV·API 키·모델·예산·전송 원인별 수정 경로 검사 통과 |
| UX-08 | 준비된 모의 연결에서 사전 검사 통과·유료 전송 0·연구 생성 0 확인 |

이전 화면의 클릭 수를 계측하지 않았으므로 클릭 감소율을 제시하지 않는다. 제거한 결정은 중복 모델 선택·중복 예산 입력·일반 설정의 역할 상세·정상 제공사 URL 입력이다. 실제 과금 시작에는 전송·예산 확인이 계속 필요하다.

## 디자인 근거

표준 range 입력의 키보드 조작을 유지하고 조작 영역을 늘렸다. [Carbon 슬라이더](https://www.carbondesignsystem.com/building-blocks/core/components/slider/guidelines), [파일 업로드](https://www.carbondesignsystem.com/building-blocks/core/components/file-uploader/guidelines), [알림](https://www.carbondesignsystem.com/building-blocks/core/components/notification/guidelines)의 구성을 참고했다.

## 남은 불편

실제 유료 연구에는 키·모델 응답 검사·단가·전송 동의가 필요하다. 양식 복구는 같은 실행 세션에 한정하며 브라우저를 닫은 뒤의 입력/파일 복구는 제공하지 않는다. 외부 검색에는 별도의 공개 검색어와 현재 연구 자료 전송 승인이 필요하다.
