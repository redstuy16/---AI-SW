# GPT 우선 연구 작업대

## 실행

```powershell
# 저장소 폴더에서 실행
.\.venv\Scripts\python.exe -m probe.workbench build/workbench/state.sqlite build/workbench/workspace --port 8766
```

기본 브라우저에서 자동으로 인증한 뒤 연구 목록을 연다. 터미널 코드를 입력하지 않는다. `--port`를 생략하면 OS 배정 포트를 사용한다. 자동 열기 실패나 `--no-browser`에서는 출력된 1회용 링크를 클릭한다. 기존 DB·작업 공간을 사용하려면 두 경로를 해당 경로로 바꾼다. CSV는 작업 공간의 `inputs` 아래에 둔다.

## 첫 연구

1. **설정 → 모델**에서 문서 확인일·단가 후보·전송 주소를 확인하고 모델 프로필을 준비한다. 목록 조회·저장은 모델을 호출하지 않는다.
2. **API 연결**에서 제공사·API 키를 함께 저장하고 모델에서 해당 연결을 선택한다. 저장한 키는 다시 표시하거나 복사하지 않는다. 환경변수가 저장 키보다 우선한다.
3. 필요한 기능 검사를 비용 동의 후 실행한다. 문서상의 지원과 계정에서 실제 호출 가능한 상태를 구분한다. 실패·미검증 상태를 저장만으로 통과시키지 않는다.
4. **새 연구**에서 질문, 성능, USD 예산, 모델, CSV를 선택한다. 성능은 `low / medium / high / max`이며 기본은 medium이다.
5. 최초 외부 전송은 **고급 설정 → 외부 전송**에서 선택 CSV를 직접 승인한다. 승인 없는 자료는 자동으로 전송하지 않는다.
6. **시작**한다. 실행 준비가 부족하면 설정 대기 연구로 저장되며 부족한 항목을 표시한다. 실제 시작은 선택 모델의 유료 호출을 허용한다.

선택 모델 하나를 네 역할에 적용한다. 다른 제공사도 모델 탭에서 선택한다. API 관리는 **API 연결**, 모델 ID 직접 입력과 역할별 구성은 **고급 설정**을 사용한다. 기존 연결과 경로 프로필을 계속 사용할 수 있다.

## 성능과 예산

| 성능 | 기존 깊이 | 요청 추론 |
| --- | --- | --- |
| low | `explore` | `LOW` |
| medium | `standard` | `MEDIUM` |
| high | `deep` | `HIGH` |
| max | `focused` | `MAX` |

지원하지 않는 프리셋 추론는 `AUTO`로 표시하고 실제 전송 매핑을 보여 준다. 직접 지정한 미지원 수준은 차단한다. 현재 실행 경로는 활성 가설 하나·최대 실험 2회이며 문헌 검색은 꺼져 있다. 높은 설정이 정확성을 보장하지 않는다.

**예산 자동 조정**은 새 일반 연구에서 기본 ON이다. 기존 CLI·저장된 연구는 `performance_profile`을 명시하지 않으면 새 적응 정책을 활성화하지 않는다. Skills·F3-P·실험적 Ridge는 계속 기본 OFF다.

요청 전에 사용액·예약액·미정산 노출·필수 완료 비용을 계산한다. 선택 후속 분석을 보류해도 Critic·필수 검증·복구 후 전체 재검증은 유지한다. 필수 비용이 부족하면 체크포인트와 부분 보고서를 남긴다. OFF에서도 연구·월·요청 상한은 적용된다. 미상 가격을 무료로 취급하지 않는다.

자동 Worker 변경은 소유자가 승인한 같은 제공사·같은 전송 주소·검사 통과·기능과 추론 호환 모델만 허용한다. 총괄·검토 역할은 유지한다. 보고서는 기본 로컬 생성이며 **AI 서술은 미실행**으로 표시한다.

## 실행 중 변경

연구의 **연구 설정**에서 미래 작업의 성능·모델·추론·예산·시간·선택 후속 작업·외부 전송·보고서 스타일을 변경한다. 변경 요청과 적용 이력을 보존한다. 예산 축소는 새 요청에 즉시 반영하고 나머지는 저장 경계에서 적용한다. 재개 시 적용한 설정을 복원한다.

질문·변수·방법·추정 대상·데이터·분할·lag·주요 지표 등 분석 의미의 변경은 **새 AnalysisPlan 연구**를 만든다. 원래 계약과 결과를 보존하며 새 계획은 기존 Manager·Worker 승인과 검증 경계를 통과해야 한다.

현재 계획 수정 API는 원래 CSV를 사용한다. 다른 CSV를 분석하려면 **새 연구**에서 CSV를 선택하고 전송·계획 승인을 다시 거친다. 실행 중인 연구의 데이터와 계약을 바꾸지 않는다.

## 키 저장과 폐기

우선순위는 환경변수 → Windows 자격 증명 관리자 → 권한 검증된 파일이다. 파일 대체 저장은 **보호된 평문**이며 암호화 저장으로 표시하지 않는다. 저장 방식·활성 출처·변경 시각·환경변수 우선 상태를 보여 준다.

키 입력은 제출 직후 성공·실패와 관계없이 비운다. 저장 키 재표시·복사 기능과 브라우저 저장은 없다. 로컬 삭제·교체는 제공사 키 폐기가 아니다. 노출된 키는 제공사에서 폐기하고 프로젝트 제한 키·제공사 지출 한도·주기적 교체를 사용한다.

이번 실행 토큰의 실제 Windows 저장 검사는 오류 `1312`로 미검증이다. 일반 사용자 로그인 세션에서 별도 검사할 수 있다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_product_ux.py -m os_secret_integration -p no:cacheprovider
```

## 보고서와 도움말

보고서는 개요·결론·근거·데이터와 방법·시각화·추가 분석 비교·검증·한계·재현의 9개 섹션을 사용한다. 검증된 수치와 등록·해시 검증된 그림만 표시한다. 기술 ID와 수치 출처는 상세 영역에 있다. 기존 정본 Markdown과 출시 검증은 유지한다.

보고서 스타일을 기술 원문으로 선택하면 정본을 먼저 표시한다. 일반 보고서는 접힌 영역에 보존하며 opt-in 내보내기는 두 형식을 포함한다.

상단 **? 도움말**과 항목별 **?**에서 의미·사용 시점·비용·주의·권장 설정을 확인한다. 도움말·설정 저장·모델 선택·성능 조정은 유료 모델을 호출하지 않는다.

## 확인 범위

오프라인 정답·고장·복구·출시·실제 Chrome 화면 검사를 실행했다. Docker 격리·Live LLM·Live Search·실제 에이전트 효능은 별도 환경 검증이 필요하다. 모의 응답의 호출 수 감소는 라이브 비용·정확도 개선의 증거가 아니다.

화면 구성은 [VS Code 모델 관리](https://code.visualstudio.com/docs/agent-customization/language-models), [Carbon 슬라이더](https://www.carbondesignsystem.com/building-blocks/core/components/slider/guidelines)를 확인해 참고했다. 목록은 [Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)의 공식 문서를 2026-10-01에 확인한 자료이며, 실제 계정 사용 가능성과 활성 가격을 대신하지 않는다.
