# 자동 검색과 조사 보고서

## 시작하기

1. **새 연구 만들기**에서 주제와 질문을 입력한다. 자료는 필요할 때 첨부한다.
2. **모델과 예산**에서 모델, 웹 검색, 예산을 정한다. 검색은 기본으로 허용하며 검색어 입력은 필요 없다. AI가 주제와 질문에서 한국어·영어 검색어를 만들고 필요한 검색을 확장한다.
3. **연구 시작**을 누른다. 검색 횟수·단가·완료 예산이 부족하거나 비밀값이 포함되면 AI 요청 전에 해당 항목을 안내한다.

검색어를 직접 정하려면 **고급 설정 → 검색어 직접 지정 · 선택**에 입력한다. 직접 입력해도 AI의 보완 검색은 함께 진행한다. 자료 전송 범위와 검색·자료 요청 상한도 고급 설정에서 조정한다. API 연결의 자료 전송 허용 항목은 연결 고급 설정에 있다.

**근거가 없으면 연구 중단**은 고급 설정의 선택 항목이며 새 연구에서는 기본으로 꺼져 있다. 문헌 근거가 부족해도 수집한 내용과 실험 설계안을 정리한다. 검증된 주장을 만들지 못했다면 **설계안 완료**로 표시하며 PDF에는 정량 결론이 미확인임을 밝힌다. 이 설정을 켜면 기존의 엄격한 중단 조건을 적용한다. 이전 연구와 명시적으로 저장한 중단 설정은 유지한다.

CSV가 없으면 문헌 근거와 실험 설계를 정리한다. 직접 측정하지 않은 속도나 실험값은 만들지 않는다. CSV가 있으면 기존 분석·검증 절차를 사용한다. 검색 결과나 읽을 자료가 부족하면 확보한 범위의 부분 보고서를 남긴다.

## 무료 검색과 공개 원문

기본 검색은 **OpenAlex → Crossref**다. OpenAlex 키 없이 시작하며 유료 검색으로 자동 전환하지 않는다. 주제·질문 또는 직접 지정한 검색어의 한국어·영어 표현과 원리 검색을 실행하고, 관련 근거를 확보하면 상충 근거도 찾는다. 새 설치는 최대 10회이며 설정 상한은 20회다. 기존 저장 한도와 전역 한도를 보존한다. 검색, DOI 보완, 할당량 확인, PDF 다운로드, 리디렉션과 재시도는 같은 요청 수에 포함된다.

무료 할당량 사용은 실제 달러 지출과 구분한다. 무료 요청에는 모델 비용 부족 대신 요청 수·시간·제공사 제한을 적용한다. AI 작업은 기존 예산 검사를 계속 통과해야 한다. 제공사 할당량·429·접속 실패가 생기면 가능한 보완 검색과 저장된 결과를 사용한다. [OpenAlex 할당량](https://help.openalex.org/access/example-costs/)

초록이 없는 관련 문헌은 DOI로 다른 제공사를 조회한다. PDF까지 읽으려면 다음 순서로 설정한다.

1. 선택 의존성을 설치한다: `python -m pip install -e ".[literature]"`. 테스트 환경에는 같은 `pypdf`가 포함되어 있다.
2. 새 연구 3장의 **고급 설정 → 공개 PDF 자동 수집**을 켠다. 기본값은 꺼짐이다.
3. 필요하면 **OpenAlex 원문 저장소 사용**도 켜고 **OpenAlex 키 관리**에서 무료 키를 저장한다. 키는 기존 안전 저장소만 사용한다. 무료 잔여량을 확인할 수 없거나 선불 유료 잔액이 있는 계정은 원문 저장소 요청을 차단한다. 일반 공개 PDF 주소는 키가 필요 없다. [원문 접근](https://help.openalex.org/access/fulltext/)

연구당 최대 3건, 파일당 10MiB·40페이지를 순차 처리한다. 읽은 페이지·읽지 못한 페이지·잘린 범위와 PDF/추출문 해시를 저장한다. 암호화·스캔 PDF는 실패 이유를 표시하며 OCR은 지원하지 않는다. 공개 HTTPS 주소와 모든 리디렉션의 목적지를 검사한다. 로그인·유료벽·CAPTCHA를 우회하지 않는다.

**SearXNG 서버**는 선택 항목이다. 사용자가 지정한 서버의 JSON 검색만 사용하며 공개 서버를 자동 순회하지 않는다. 명시적인 `http://127.0.0.1:포트` 로컬 서버도 연결할 수 있다. 서버의 JSON API가 꺼져 있으면 연결 실패를 기록한다. 웹 결과는 원문을 찾는 단서로만 사용하고 초록으로 저장하지 않는다. [SearXNG API](https://docs.searxng.org/dev/search_api.html)

## 연구 화면

- **개요**: 연구 질문, 핵심 결과, 현재 결론의 사용 범위, 최근 변화와 바로 가기를 확인한다.
- **연구 흐름**: 전체 연구 → 자료·근거 → 실험·분석 → 검증·복구 → 실행 도구 범주에서 작업과 상태를 확인한다. 전체 연구에는 7단계 미니맵과 최근 5개 변화가 있다. 저장된 연구 관계를 펼치고 항목을 누르면 오른쪽에 상세를 연다.
- **근거·자료**: 인용과 출처를 확인한다. ‘인용 확인’은 출처 참조 검사의 결과다.
- **보고서**: PDF 페이지 이동, 확대·축소, 너비 맞춤, 검색, 목차, 다운로드를 사용한다. **근거 보기**로 출처를 함께 읽는다.

실험 설계의 변인 관계도는 **설계안**으로 표시한다. 기존 진행 기록·실험/분석·검증은 같은 연구 화면의 탭에서 연다. 상단에 사용 비용과 남은 예산이 표시된다.

연구 흐름과 개요에는 요청·관련 문헌·읽을 수 있는 자료·검증된 근거 수가 표시된다. 대상과 조건이 일치하는 문헌과 원리를 설명하는 간접 문헌을 구분한다. 원문 근거의 **원문 N페이지**를 누르면 보고서 옆에서 해당 페이지를 읽을 수 있다. 조회·새로고침·PDF 페이지 이동은 검색이나 AI를 실행하지 않는다.

관련 문헌 부족, 초록·원문 없음, 요청 제한, 보고서 실패는 별도로 표시한다. 제목만 확보한 문헌에서는 결론을 만들지 않는다. 요청한 음료 5종의 비교 측정값이 없으면 표에 **미확인**을 표시한다. 탄산수 등 간접 자료의 수치를 음료별 측정값으로 바꾸지 않는다.

CO₂ 용해처럼 기체 방출의 원리를 설명하는 자료는 **간접 근거**로 사용할 수 있다. 실제 방출 속도나 음료별 측정 결과로 해석하지 않는다. 무관한 문헌과 검증하지 못한 인용은 계속 제외한다.

## 작성·수정

새 연구 화면으로 만든 연구는 선택한 모델로 보고서 본문과 그림 참조를 작성한다. 앱은 기록된 수치·그림·인용을 검사한 뒤 PDF를 조판한다. 시작 예산에 작성 비용이 포함된다. PDF를 다시 열거나 저장하는 동작은 AI를 호출하지 않는다.

**AI 보고서 다시 작성 · API 호출**은 별도 유료 요청이다. 현재 상태 버전·중복 요청·남은 예산을 검사한다. 자료나 질문이 바뀌면 이전 보고서를 현재 결과로 사용하지 않는다. 계산 연구는 **계산 다시 확인하기**가 먼저 필요하다.

재계산으로 자료가 바뀌면 이전 AI 본문을 이력에 보존하고 현재 검증된 계산으로 무료 부분 보고서를 만든다. 새로운 AI 본문은 재작성 버튼으로 요청한다. 재계산 버튼으로 유료 보고서 요청을 보내지 않는다.

새 자동 모델 설정은 계획 1,024토큰, 보고서 최대 4,096토큰을 구분한다. 기존 수동 설정·모델 상한·달러 예산이 우선한다. 제공사가 출력 한도 종료를 확인했고 비용 정산과 남은 예산이 확보된 경우에만 최대 한 번 재작성한다. 그 외 실패는 작업을 실패로 마감하고 확보한 근거와 설계로 부분 보고서를 남긴다. [출력 한도와 추론 토큰](https://developers.openai.com/api/docs/guides/reasoning)

검색 동의가 없어 종료된 과거 연구는 기록을 그대로 둔다. **검색 설정을 보완해 다시 연구**로 새 초안을 열면 검색이 기본 허용된다. 모델·예산을 확인해 다시 시작한다.

## 호환성

기존 API 요청의 `ai_report_enabled` 기본값은 `false`다. API로 새 조사 보고서 경로를 사용하려면 `settings_version: 2`, `ai_report_enabled: true`를 지정한다. 새 설정은 검색 허용이 기본이며 검색어를 생략하면 연구 질문에서 만든다. 명시적인 `public_search_consent: false`와 과거 설정의 차단은 유지한다. 기존 API 연결·예산·정본 저장 검사를 그대로 통과해야 한다.

기존 Skills·F3-P·Ridge·Research Slice·Cycle 5 설정은 바꾸지 않는다. 보고서 원본은 `research_output/ai_report.json`으로 기존 내보내기 목록과 해시 검사에 포함된다.

공개 원문은 기존 artifact·정본 쓰기·복구 구조로 저장하며 DB migration은 없다. 준비된 PDF·페이지 추출문·색인은 release의 `source_documents/`에 포함된다. 변조·오래된 출처·비밀값은 조회·인용·내보내기에서 차단한다. 기존 연구는 소급 변경하지 않는다.
