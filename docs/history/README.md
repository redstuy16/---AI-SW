# 개발 기록 안내

날짜별 연구일지와 브라우저 검사 원본은 로컬에 보관하며 Git과 제출용 ZIP에서 제외합니다. 개인 작업 시각·사용 비용·PC 경로가 포함될 수 있습니다.

앱 실행 코드, 테스트, 고정 예시 자료와 공개 검증 문서는 유지합니다.
