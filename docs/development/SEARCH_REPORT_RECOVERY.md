## 미정산 연구의 삭제 수정

연구를 휴지통으로 옮기는 작업에도 정산 완료 검사 `_idle`을 적용해, 중단된 미정산 연구의 삭제가 막혔다. 실행 상태·작업 프로세스 검사 `_inactive`를 분리하고 휴지통 이동에 적용했다. 보고서 갱신·재계산·영구 삭제의 정산 검사는 유지한다.

- 미정산 연구를 목록에서 삭제하고 휴지통에서 복원할 수 있다. 휴지통 이동은 연구 원문·보고서·응답 체크포인트·지출 원장을 변경하지 않는다.
- 진행 중인 연구와 살아 있는 실행기는 계속 삭제를 차단한다. 삭제로 미정산 노출이나 월 예산 계산이 바뀌지 않으며 불확실한 요청의 재전송도 차단한다.

## 과학 모드와 이전 실행 경로 분리

현재 `SCIENCE_AUTO`는 다음 행동을 선택하는 판단 역할부터 시작한다. 이전 기후 전용 절차와 네 역할을 순차 호출하던 시작 조건을 그대로 적용해, 지원 범위·모델 준비·비용·문맥 검사에서 실행이 막히고 있었다.

- `uses_qualified_profile`로 전용 절차 적용 범위를 이전 실행 경로에 한정했다. 새 초안에서는 사용하지 않는 전용 절차 설정을 끈다. 이미 저장된 과학 초안의 `AUTO` 설정도 일반 연구를 차단하지 않는다.
- 상세 조건 확인·저장·수정·실제 도구 검사에 같은 적용 기준을 사용한다. 사용하지 않는 기후 절차의 두 기간·고정 방법 제한이 일반 상관 분석에 적용되지 않는다. 자료 연결·입력 조건 충돌·실제 미지원 방법 검사는 유지한다.
- 과학 모드에서는 기후 주제라는 이유로 검색이 필요 없다고 처리하지 않는다. 검색 동의·필수 검색·횟수·문맥·비용 검사를 실제 검색 설정에 맞게 적용한다.
- 시작 준비와 최소 호출 비용은 실제 필수 역할인 `manager` 기준으로 검사한다. 선택 역할의 연결·기능·인증·가격·문맥·전송 범위는 실제 호출 직전에 중개기가 검사한다. 이전 실행의 네 역할 검사는 유지한다.
- 문맥은 호출 역할의 모델 한도에 맞게 계산한다. 사용하지 않는 작은 모델이 판단 역할의 문맥을 줄이지 않는다.
- 새 과학 연구에 CSV를 지정해도 현재 설정 형식 2를 기본으로 쓴다. 명시적으로 지정한 형식과 이전 연구의 기본 형식은 보존한다.

기후 전용 모듈은 과거 연구의 원문 검사·결론 검증·재현에 실제로 사용하므로 삭제하지 않았다. 원장과 월 노출, 불확실한 요청의 재전송 차단, 원문·자료 해시, 출처·수치·보고서 검증, 전송 동의, 종료되지 않은 실행기 검사는 계속 적용한다. 준비된 수치 자료가 필요한 조건도 유지하며 실제 계산 없이 결과를 만들지 않는다.

## 과거 비용과 새 요청의 분리 (2026-10-06)

휴지통 수정 후 요청 범위가 새 연구·재개·보고서 작성 전체로 확대됐다. 같은 연구의 `UNRESOLVED` 원장이 있으면 모든 후속 요청을 막던 조건과, 과거 비용을 현재 실패의 원인으로 다시 표시하던 조건을 수정했다. 비용을 0으로 바꾸거나 정산이 끝난 것으로 표시하지 않는다.

- 새 요청은 과거 미정산 예약액을 연구·월 한도와 완료 예산에 포함한 뒤 허용한다. 내부 연구 예산도 확정 비용과 미정산 예약액을 함께 반영한다. 월이 바뀐 과거 노출도 유지한다.
- 중개 요청의 지문과 예약을 원자적으로 연결한다. 같은 실행에서 응답 없는 동일 요청을 자동 재전송하지 않는다. 아직 실행 중인 요청, 이미 완료한 요청, 결과를 알 수 없는 요청을 다른 코드로 구분한다.
- 사용량·응답 식별자가 감사 기록과 일치하는 저장 응답은 비용이 미확정이어도 전송 없이 재사용한다. 미확정 금액은 그대로 유지한다. 검색도 완료된 요청·사용량 검증을 거쳐 복구하며 손상된 캐시의 기존 차단은 유지한다.
